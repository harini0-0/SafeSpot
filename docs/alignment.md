## Coordinate frame
- **Units:** meters for all three sources.
- **Axes:** model space, X/Y on the floor plane, **Z up**. The mesh OBJ is in the
  same frame (its Z is height: 0 = floor, max = ceiling).

- **Offset mesh↔rooms (floor plane):** ΔX ≤ 16.4 cm, ΔY ≤ 2.9 cm at the

  **centerlines**; the mesh is the wall **surface**), so the transform is the
  **identity** — no rotation, no translation. No correction is applied.

## Wall centerline → nearest mesh surface
- Samples: 321 points along 38 unique wall edges (0.25 m spacing).
- **Median distance: 5.2 cm**
- 95th percentile: 25.7 cm
- Worst: 81.1 cm (edge `xpgyhy80hk` in Bedroom)

A small, roughly wall-half-thickness distance confirms the boundary lines lie on
the mesh walls. Larger worst-case values occur where the mesh is open (doorways,
the open Hallway–Living Room boundary) and have no nearby surface.

## Texturing status (Phase C1)
- The **50k mesh has no texture coordinates** (`vt`) and no material, so a
  synthesized MTL cannot texture it — there is no UV mapping to the 50k atlases.
- The only UV-bearing mesh is a **single room chunk** (`500k` lod2) whose texture
  (`lod2_room0_chunk4096_000.jpg`) ships only in the `matterpak`/`obj` bundles,
  which are currently **`unavailable`** from the API.
- Therefore no synthesized-MTL textured mesh is produced yet. See the Phase A/C
  report for the options (generate the bundle via `generateBundleAssets`, or use
  the 4k panorama skyboxes for photorealism). **No UVs or textures were fabricated.**
